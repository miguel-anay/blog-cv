# Decisiones de arquitectura (ADR)

Cada archivo registra una decisión: el contexto, lo que se decidió y sus consecuencias. Una decisión no se
edita después de aceptada; si cambia, se escribe un ADR nuevo que la reemplaza y se marca el anterior como
`Reemplazado por NNNN`.

| ADR | Decisión | Estado |
|---|---|---|
| [0001](0001-docs-desde-github.md) | Publicar la documentación de los repos leyéndola de GitHub | Aceptado |
| [0002](0002-sin-login.md) | El blog no tiene login; los exámenes usan un invitado anónimo | Aceptado |
| [0003](0003-diseno-mintlify.md) | Lenguaje visual de Mintlify con tokens CSS | Aceptado |

Para una decisión nueva, copiá la estructura de cualquiera: **Contexto**, **Decisión**, **Consecuencias**.
